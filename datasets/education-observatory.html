Changes with different meanings

MIT

LLMs inside an existing course

The verified 2026/27 Software Design description explicitly includes using LLMs in design and coding. The 2024/25 description did not state that component. The course is an option, not individually required for all 6-3 students.

Official catalogue
Wisconsin–Madison

A broad choice becomes two specified fields

The CS BS changes from a broad two-course mathematics selection to one linear algebra choice and one probability or statistics choice. A requirement can change even when familiar course names remain.

Official catalogue
Waterloo

A newly explicit option was already permitted

Two enriched course substitutions appear explicitly in the later programme table, but earlier course descriptions already allowed them. Reading the table alone would overstate the change.

What this measures

The issue compares curriculum documents and selected course descriptions. It records requirement categories, permitted alternatives and content changes, preserving each institution’s programme and version definitions.

All 13 cards received separate AI-agent review against original evidence; eight course records were spot checked. This is purposive selection, not a population accuracy estimate.

The 2025/26 editions remain a gap. These records do not establish actual teaching, student choices, learning outcomes or global AI adoption. The wider 20-university base has not all been updated to 2026/27.
