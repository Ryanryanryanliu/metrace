Method

We work from what was actually published, on the day it was published. Every value in our files can be traced to an archived page.

Sources

We pull the full list of archived captures for each source site from the Internet Archive's Wayback Machine, then fetch the pages, PDFs and data files that matter. We also read live sites directly: government search portals and open-government catalogues fill in documents the archive missed.

Reading

Language models read each archived version. For statistics offices, two detectors propose candidate events: one watches the stream of file names and folders, the other compares the text of successive releases and calendars. For bank rate pages and rate cards, a parser reads every table and keeps the effective date the bank stated.

Checking

Two model reviewers code each candidate independently against a written manual. A third model settles disagreements. Every event we publish is confirmed by a source outside the office, then a separate agent tries to refute it.

Dates

We keep three dates where they exist: when the change took effect, when the source announced it, and when an archive first captured it. A capture date is evidence that something was public by then, not the release date.

Corrections

When a source revises a value or a page changes, we add a new row and keep the old one, so any past date can be reconstructed as it looked then.
