How we measure

  1. Pull

    Every archived capture of the sources, plus live sites, documents and data files.

  2. Read

    Language models read each version, in any language, and record what it says and what changed.

  3. Check

    Two independent model reviewers code each case and a third settles disagreements. Outside sources confirm every event.

  4. Deliver

    Point-in-time files and feeds in which every row carries a date and a source.

Why Metrace

Rigorous method

Measurement designed by an economist: lists fixed before the pipeline runs, gold sets, independent coders and a reviewer whose job is to refute.

Micro data, macro answers

Bank by bank, agency by agency, firm by firm, built to answer questions about pass-through, fiscal stress and policy shocks.

Validation ships with the data

Every dataset comes with its tests against known events and ground truth. Rows are stored as first published, so backtests see no hindsight.

One engine, every domain

The same pull, read and check steps work for statistics offices, bank pages and government notices. Three datasets took two weeks.
